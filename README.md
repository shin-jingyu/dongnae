# 🥕 동네마켓: 자유로운 중고거래 플랫폼

## 🌟 프로젝트 개요
동네마켓은 사용자가 지역 내에서 중고 물품을 거래하고 커뮤니티 소통을 할 수 있는 플랫폼입니다. 중고거래의 편리성과 커뮤니티 기능을 결합해 지역 사회의 소통을 목표로 합니다.

## 🛠️ 개발 환경 및 기술 스택

- **백엔드**: Spring Legacy, Spring Security, MyBatis, MySQL
- **프론트엔드**: HTML, CSS, JavaScript, Bootstrap
- **데이터 관리**: 파일 업로드 및 관리 (프로필 이미지 및 상품 이미지)
- **통합 개발 환경 (IDE)**: Eclipse
- **JDK 버전**: JDK 11
- **빌드 툴**: Maven
- **관리 툴**: GitHub

## ✨ 주요 기능

- **회원 관리**: 가입/로그인, 인증 시스템 (Spring Security)
- **상품 거래**: 중고 물품 등록, 이미지 업로드, 거래 관리
- **커뮤니티 기능**: 게시판을 통한 사용자 간 소통
- **결제 기능**: 안전한 결제 시스템 (카카오페이 등)
- **포인트 관리**: 적립된 포인트 조회 및 사용
- **키워드 및 알림**: 관심 키워드 등록, 관련 상품 알림
- **검색 및 카테고리**: 키워드/카테고리별 검색 기능
- **찜 및 채팅 기능**: 찜 목록 관리, 실시간 거래 채팅

## 🔍 프로젝트 분석

- **목적**: 중고 거래와 커뮤니티 소통을 결합해 지역 경제와 유대감 강화
- **타겟 사용자**: 지역 기반 중고 거래를 원하는 사용자

## 💻 기술적 특징

- **아키텍처**: Spring Legacy 기반의 MVC 아키텍처
- **파일 업로드**: 프로필/상품 이미지 업로드, UUID 적용
- **프론트엔드 설계**: 반응형 웹 페이지 (Bootstrap)
- **포인트 및 리뷰**: 거래 후 포인트 적립, 리뷰 기능
- **키워드 알림**: 맞춤형 알림 기능
- **결제 시스템**: 안전한 결제 지원
- **커뮤니티 및 채팅**: 실시간 채팅으로 소통 강화

## 🚀 프로젝트 특징

- **사용자 친화적 설계**: 지역 거래와 소통을 편리하게 연결
- **반응형 웹 디자인**: 모바일 및 다양한 기기에서 일관된 경험 제공
- **커뮤니티 중심 소통**: 중고 거래 및 정보 공유 활성화

## 📈 개선 및 향후 과제

- **기술 스택 업데이트**: Spring Boot로 마이그레이션해 유지보수성, 확장성 개선

## 📜 기능 구현 계획

### 1. 회원 관리 - 이현지
- **회원가입 및 로그인/로그아웃**: Spring Security를 이용한 인증 및 보안 기능 구현
- **회원 정보 수정 및 탈퇴**: 사용자 정보 업데이트 및 계정 관리
- **거래 관리**: 판매 중 상품, 판매/구매 내역, 찜 목록 관리
- **후기 및 알림**: 거래 후기 작성, 키워드 알림 설정 및 해제
- **포인트 관리**: 포인트 충전 및 내역 관리
  
### 2. 상품 관리 - 성노빈
- **상품 등록/수정/삭제**: 상품 정보 입력 및 이미지 업로드 기능
- **상품 목록 및 상세 페이지**: 메인 및 카테고리별 상품 리스트 제공, 상세 정보 표시
- **검색 및 정렬**: 키워드 및 카테고리 검색, 다양한 정렬 옵션 제공
- **찜하기 기능**: 관심 상품을 찜 목록에 추가

### 3. 거래 기능 - 성노빈 & 이현지
- **상품 구매:**: 상품 구매 절차 구현 및 결제 연동 (카카오페이 등)
- **거래 채팅**: 구매자와 판매자 간 실시간 채팅 기능
- **송금하기**: 안전한 결제 기능을 통한 거래 보장
  
### 4. 커뮤니티 기능 - 신진규
- **게시판 관리**: 카테고리별 및 지역별 커뮤니티 게시판 제공
- **게시글 기능**: 게시글 검색, 등록, 수정, 삭제 및 좋아요 기능
- **댓글 기능**: 댓글 등록, 수정, 삭제를 통해 사용자 간 소통 강화

### 5. 반응형 웹 디자인 - 김주영
- **반응형 웹 디자인**: Bootstrap 사용해 모바일 및 다양한 기기에서의 일관된 사용자 경험 제공
